### Method notes (worth reusing)
- Used the **TypeScript compiler API** (`ts.createSourceFile` + parent map), NOT regex.
  Regex is unusable here: it cannot tell `status === "ACTIVE"` (enum) from
  `<span>Active</span>` (rendered text).
- Key idea: a strict `isRendered()` walk that only passes through nodes whose
  value is actually rendered — JsxExpression child, ternary whenTrue/whenFalse
  (never the condition), ArrayLiteral via `.map`, toast/alert calls, and
  user-facing object props (`header`/`label`/`title`). Everything else
  (BinaryExpression, if/switch/case, variable decl) terminates as non-rendered.
  This alone removed ~900 false positives (v1: 2,276 → v2: ~1,390).
- Must also filter: CSS/Tailwind token strings, `<style>`/`<script>` contents,
  HTML entities (`&apos;`), translation keys, routes, colours, date-format
  patterns, and single-token technical identifiers.
- Screen attribution: BFS the static import graph from each `page.tsx`
  (plus ancestor `layout.tsx`). Single-owner → that page; multi-owner → fall
  back to domain folder (`components/students/*` → `/students`); remainder →
  "cross-screen". Without the domain fallback, students collapsed into a
  343-item shared bucket and looked clean when it wasn't.

### Environment gotcha
**Source files were being rewritten by another process during the audit**
(one file every ~20s: leaves, accounting, certificates, health, expenses, …).
This caused a phantom 12-line offset that looked like a scanner bug — it was
drift, not a bug. Always scan + verify + report in a SINGLE process so the
snapshot is atomic, and re-run before acting on line numbers.
